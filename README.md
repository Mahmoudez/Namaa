# EduFlow School App Demo

A self-contained, offline-friendly school management app demo built with HTML, CSS, and vanilla JavaScript.

## Run

Open `index.html` in a modern browser. No install, server, network access, or build step is required.

## Project files

- `index.html` — app shell and mobile/PWA metadata.
- `css/styles.css` — responsive interface, phone frame, themes, and components.
- `js/app.js` — demo data, local storage, role-based screens, and app interactions.
